# Test roms

Only roms their authors published for free download live here, so the tests
run anywhere, CI included. Anything commercial stays on the machine that owns
it and is passed to `run-gate.sh` by path.

- `sprilo.nes` - Sprilo, a homebrew racing game by cbrwn (mapper 0, 16KB PRG,
  8KB CHR, vertical mirroring), made for GitHub's Game Off 2017 and also used
  as quickerNES's free test rom. Its source is public at
  <https://github.com/cbrwn/gameoff>. That repository has no licence file
  (looked 2026-10-13), so no licence says the rom may be passed on: it is
  here as its author published it, and not under this repository's licence.
  If you are its author and want it removed, say so in an issue and it goes.
