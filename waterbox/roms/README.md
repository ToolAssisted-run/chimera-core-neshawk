# Test roms

Only freely licensed roms live here, so the gate runs anywhere, CI included. Anything commercial
stays on the machine that owns it and is passed to `run-gate.sh` by path.

- `sprilo.nes` — a homebrew NROM racing game (mapper 0, 16KB PRG, 8KB CHR, vertical mirroring),
  also used as quickerNES's free test rom.
